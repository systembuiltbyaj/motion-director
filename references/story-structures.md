# Story Structures

Every reference follows the same arc. Durations assume 128 BPM (1 beat ≈ 0.47 s). Round each beat
start with `snapToBeat`.

## The arc

```
HOOK → TENSION → TURN → PROOF ×3–5 → MONTAGE → PAYOFF → LOCKUP → CTA
```

| Beat | Job | Typical moves |
|---|---|---|
| Hook | One line that makes the claim or opens a question. The motif enters. | Build-a-sentence (fill), guide motif |
| Tension | The problem or status quo. | Word swap, build (color), whip |
| Turn | The product/answer arrives, as punctuation. | Flash card + echo, zoom-through |
| Proof | One feature per beat: a line plus visual proof. | Tilted UI, prompt → chips, slot focus, stat punch, panel push |
| Montage | "And everything else", fast and on the beat. | Bento reconfigure, chip rows, list stack, logo wall |
| Payoff | The single sentence the viewer should remember. | Build-a-sentence (fill), a long hold |
| Lockup | Brand mark + role line. | Arrive with scale-down, motif returns |
| CTA | A question or action with its keyword highlighted. | Build-a-sentence, caret blink |

## Templates

**15 s (social teaser)**: Hook 0–3 · Tension 3–6.5 · Turn 6.5–8 · Proof ×1 8–11.5 · Stat 11.5–13 · Lockup + CTA 13–15.
(Each layout demo in `assets/demos/` is a worked 18–24 s example: see `layouts.md` for which to start from.)

**30 s (launch / promo)**: Hook 0–3 · Tension 3–6 · Turn 6–7.5 · Proof ×3 7.5–19 (3.5–4 s each) ·
Montage 19–23 · Payoff 23–26 · Lockup + CTA 26–30.

**45 s (product / agency promo)**: Hook 0–3.5 · Tension 3.5–7 · Turn 7–9 · Proof ×4 9–25 ·
Flash card 25–26.5 · Montage 26.5–33 · Payoff 33–37 · Lockup 37–41 · CTA 41–45.

**60 s (brand film / portfolio)**: Hook 0–4 · Tension 4–9 · Turn 9–11 · Proof ×5 11–33 ·
Flash 33–34.5 · Montage 34.5–43 · Values/Principles 43–50 · Payoff 50–54 · Lockup + CTA 54–60.

Openers differ by layout (full structures in `layouts.md`):
- **Brand System:** cinematic image + huge caps title, then a hard cut to a black serif statement.
- **Narrated Journey:** the motif appears and the first spoken line builds word-for-word with the voice.
- **Launch Hype:** 50/50 split, a line on one side and a huge stat on an accent panel.
- **AI Canvas:** a title in the atmosphere morphs into a prompt box and the brief types itself.
- **Agency Split:** the mark pops and the name types, its second line swapping before it lands.

## Copy rules

- ≤ 8 words per line and ≤ 2 lines per beat. Split longer thoughts across beats.
- Each line gets exactly one keyword to highlight. If you can't pick one, the line isn't sharp yet.
- Claims need proof on screen in the same beat (a UI card, stat, footage, or logo).
- Stats and client names come from AJ or the client, never invented.
- The CTA is a question ("Ready to build yours?") or a direct action ("Book a call"), with the
  keyword highlighted.

## Aspect ratios

| | 16:9 (1920×1080) | 9:16 (1080×1920) | 4:5 (1080×1350) |
|---|---|---|---|
| Sentence size | 80–100 px | 84–110 px (it's relative to the short side) | 80–96 px |
| Split layout | side by side | stacked: panel on top, media below | stacked or 60/40 |
| Tilted UI | right 45% | centered, below the copy | centered |
| Safe margin | 8% x / 8% y | 8% x / 12% y (UI overlays) | 8% x / 10% y |
| Hero word | 180–300 px | 160–240 px, may wrap onto 2 lines | 160–240 px |

Keep the same beats and moves across aspects. Re-layout, don't re-time.
